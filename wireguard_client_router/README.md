# WireGuard Client Router

Connect Home Assistant as a client to an existing WireGuard server and make
selected private LAN devices reachable by remote WireGuard peers.

Use **Open Web UI** to upload or paste an existing WireGuard `.conf`, review
the restricted routing policy, activate it, and monitor the live tunnel status.

For setup instructions and network examples, open the **Documentation** tab or
read [DOCS.md](DOCS.md).
